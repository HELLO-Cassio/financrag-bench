# 零售银行合规子领域范围声明 v0.1

状态：**草案，待团队确认与评审；尚未冻结。** 创建日期：2026-10-24。

## 1. 一句话范围

本基准拟覆盖中国境内零售银行业务中，由公开法律、行政法规、部门规章和规范性文件明确规定的合规要求，重点研究“业务行为—监管要求—依据条款”的多跳关系。

## 2. 覆盖范围

拟覆盖个人贷款（消费贷、经营贷）、互联网贷款、信用卡与分期、消费者权益保护（告知、收费、催收）、征信与个人信息。这里只纳入与零售银行直接有关的公开要求。

## 3. 不覆盖

证券、保险、信托、跨境业务；地方性法规及地方细则；内部制度和其他非公开文件；依赖个案裁量的主观结论。跨行业文件只截取与本范围相关的适用关系，不扩展研究主题。

## 4. 时间边界

沿用手册的拟定基准日 **2026-10-23**（中国标准时间），以该日已公布且有效的官方文本为主要研究对象；这不是对任何候选文件有效性的确认。实际下载日期独立记入 `fetched_at`，不得倒填。基准日后文件不混入此快照，需另立版本。

至少保留 2 份历史文本；用 `superseded` / `repealed` 及明确失效日期描述。为避免混淆，本数据集中 `status` 表示基准日状态，核验日期和证据记在 `verification_log.csv`。尚未生效的文件不进入本版正式语料；留在候选清单中。

## 5. 规模与准入

- 总量 15–25 份；核心 3–5 部；非核心配套合计 10–20 份（含配套、旧版、解释）。
- 后续解析目标 800–2000 条条款，最终以 E2 实际统计为准；问答规划约 200 道，当前均未生成。
- 准入三问：是否直接影响本范围判断？是否官方公开可获取？是否能与其他入库文件形成依据、适用、例外或修订关系？
- 不满足主证据条件的政策解读只能标为“解释”，不得冒充法律效力层级。
- 若规模失控，优先评审是否收缩为“个人贷款 + 消保”；收缩决定须记录，不能默默删除语料。
