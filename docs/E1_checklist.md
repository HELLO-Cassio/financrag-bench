# E1 验收清单

状态：未验收。全部完成后才能冻结；仓库初始化不等于 E1 完成。

## 范围和规模

- [ ] 一页范围说明经团队确认，覆盖/排除/时间边界完整。
- [ ] 正式清单总量 15–25 份；核心 3–5 部；非核心 10–20 份。
- [ ] 核心覆盖基本法、业务办法、消保；每部有至少 2 份配套引用/提及证据。
- [ ] 核心每部至少可支持 20 道单跳/多跳题的设计已检查。
- [ ] 配套至少覆盖同主题规章、通知、消保、解释、历史版本五类。
- [ ] 至少 2 份历史版本，失效时间和替代关系清楚。
- [ ] 五类题实际覆盖矩阵完成，全局类有同主题至少 3 份文件。

## 来源和文件

- [ ] 所有材料公开、官方可追溯，不含付费数据库或内部资料。
- [ ] 每行有详情 URL、真实下载日期、效力层级、正确 SHA256。
- [ ] 发布/生效/失效日期及基准日状态逐份查证。
- [ ] 文件、文件夹与 doc_id 一致，PDF 首尾可打开、文字及表格完整。
- [ ] 无同一版本/同一内容重复；HTML 转存、OCR 和附件情况已记录。
- [ ] 旧版 replaced_by 指向正确且已入库的新版。
- [ ] 运行 `python scripts/validate_manifest.py docs/manifest.csv --mode release` 成功。

## 独立复核与评审

- [ ] 非采集成员随机抽 5 份，官网标题/文号/日期/状态全部一致；若有错误重核全量。
- [ ] 未参与同学能在 10 分钟内复述范围、文件选择和五类题证据。
- [ ] 导师/法务背景同学评审五个问题，scope.md 记录真实姓名、日期、意见与处理。
- [ ] 核验日志和关系证据完整；解释材料不作为主证据。
