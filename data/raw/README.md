# 原始文件存放规则

每份已采集法规建立 `DOCxx/` 文件夹，原文命名为 `DOCxx_简称_类型_版本状态.pdf`。编号按纳入顺序分配，不因排序改变。初始化没有真实法规，因此不创建虚假的 DOC01/DOC02 原文。

优先官方 PDF/Word 附件；只有 HTML 时将完整页面转存 PDF，在 notes 写“HTML 转存”、详情 URL 和真实下载日期。原始 HTML 可作为附加存档保留。文件必须有正文和附则；表格与附件不可遗漏。

同目录附件保留可辨识名称及 DOC 前缀，并在 notes 记录文件名/哈希。主文件 local_path 和 sha256 写入 manifest；先核对再交给 E2。
